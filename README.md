## 🌟 주요 기능 소개

1. **4대 운세 주기 선택**
   - ☀️ **오늘 하루 운세**: 오늘 하루를 관통하는 핵심 기운과 실천적 조언
   - 🌙 **금주 운세**: 이번 주의 주요 흐름과 전환점
   - ✨ **이번달 운세**: 한 달 동안 맞이할 기회와 주의점
   - 🌌 **3개월 운세**: 중기적 비전과 운명의 도약

2. **주관식 질문 맞춤형 해석**
   - 질문자가 직접 입력한 질문(연애, 이직, 시험, 금전, 대인관계 등)의 맥락을 깊이 있게 공감하여 구체적인 답변을 제공합니다.

3. **78장 풀 덱 인터랙티브 스프레드**
   - 메이저 아르카나 22장 + 마이너 아르카나 56장(완드, 컵, 소드, 펜타클)
   - 파노라마 아크 뷰에서 사용자가 직관에 이끌려 직접 3장의 카드를 선택
   - 정방향(Upright)과 역방향(Reversed)의 다채로운 상징 체계 완벽 구현

4. **Gemini AI & 내장 오라클 엔진 듀얼 시스템**
   - **Google Gemini 2.5 Flash / 1.5 Pro REST API**를 통해 실시간 심층 운세 풀이
   - API 키가 없어도 누구나 즉시 고품질 해석을 감상할 수 있는 **내장 오라클 엔진(Built-in Mystic Engine)** 탑재

5. **감성적 UX / 비주얼 & 사운드**
   - Web Audio API를 활용한 신비로운 셔플음, 차임음, 카드 플립 효과음
   - 캔버스 별빛 파티클 및 3D 카드 플립 애니메이션
   - 모바일 스마트폰, 태블릿, PC 완벽 반응형 지원

## 🔑 Gemini API Key 발급 및 설정 안내
본 서비스는 API 키 없이도 내장 오라클 엔진으로 100% 정상 작동하지만, Gemini AI만의 깊이 있는 문학적 리딩을 원하시면 개인 API 키를 등록하실 수 있습니다:
1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속 (무료)
2. **"Create API key"** 클릭 후 키 복사
3. 대시보드 우측 상단 **[Gemini API 설정]** 버튼 클릭 후 붙여넣기 (로컬 브라우저에만 안전 보관)
