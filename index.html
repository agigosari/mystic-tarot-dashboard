Gemini API Key 설정

Google AI Studio에서 무료로 발급받은 Gemini API 키를 입력하시면, 당신만의 전용 인공지능 타로 마스터가 활성화됩니다.

입력하신 API 키는 서버로 전송되지 않으며, 오직 본인 브라우저의 로컬 스토리지에만 안전하게 보관됩니다.
API 키가 없으신가요? (무료 10초 발급)
  1. Google AI Studio (aistudio.google.com) 에 접속합니다.
  2. Google 계정으로 로그인 후 "Create API key" 버튼을 클릭합니다.
  3. 발급된 키를 복사하여 위 입력창에 붙여넣고 저장하세요. (평생 무료 한도 제공)

💡 키를 입력하지 않으셔도 내장된 고성능 타로 오라클 해석 엔진이 완벽하게 운세를 풀이해 드립니다!
